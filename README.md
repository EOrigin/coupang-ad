# 쿠팡 광고(AI 스마트광고) 옵션 ID 크롤러

쿠팡 광고 관리자(`광고 관리` > `매출 성장`) 내 모든 AI 스마트광고 캠페인을 자동으로 순회하며, 조건에 맞는 상품의 **옵션 ID(vendorItemId)** 및 성과 지표(집행 광고비, ROAS, 매출)를 일괄 수집하는 크롤러입니다.

---

## 🎯 주요 기능
1. **🟢 ON 상태인 모든 스마트광고 캠페인 자동 순회**:
   - 대시보드 내 전체 페이지를 순회하여 **ON(진행중)** 상태인 캠페인만 정확하게 식별
   - OFF(중지) 상태인 캠페인은 자동 제외하고, **ON 상태인 캠페인은 누락 없이 모두 상세 분석**
2. **조건 필터링**:
   - 최소 집행 광고비 (기본값: **5,000원 이상**)
   - 최대 광고 수익률 ROAS (기본값: **600% 미만**)
3. **페이지네이션 자동 처리**: 캠페인 목록 및 캠페인 내 상품이 다수일 경우 끝까지 자동 페이지 넘김
4. **캠페인별 결과 분류**: 캠페인명 단위로 그룹화된 결과 및 고유 옵션 ID 목록 제공
5. **3가지 포맷 자동 저장 (`output/`)**:
   - `coupang_ads_YYYYMMDD_HHMMSS.xlsx` (Excel 리포트: 캠페인별 성과 요약, 구분 상세 및 캠페인별 개별 시트 [옵션ID, 광고비, ROAS, 매출, 상품명])
   - `coupang_ads_YYYYMMDD_HHMMSS.json` (구조화된 상세 JSON 데이터)
   - `option_ids_YYYYMMDD_HHMMSS.txt` (옵션 ID만 한 줄씩 나열, 복사/일괄 처리에 용이)
6. **로그인 세션 유지**: 브라우저 프로필(`browser_profile/`)에 로그인 상태가 영구 보존되어 매번 로그인할 필요가 없음

### 📊 엑셀 (XLSX) 리포트 구성
- **시트 1: [캠페인별 요약]**
  - **1. 성과 요약 테이블**: 캠페인명, 조건부합 상품수, 총 광고비, 총 매출, 평균 ROAS 및 [전체 합계]
  - **2. 캠페인별 구분 상세 목록**: 각 캠페인 타이틀 배너 아래에 `옵션ID | 광고비 | ROAS | 매출 | 상품명` 표와 캠페인별 소계 제공
- **시트 2: [전체_상품목록]**
  - 전체 수집 상품 통합 테이블 (자동 필터 적용, `캠페인명 | 옵션ID | 광고비 | ROAS | 매출 | 상품명`)
- **시트 3+: [캠페인별 개별 시트]** (예: `테스트`, `26SS 여성`, `26SS 남자` 등)
  - 캠페인 전용 탭으로 `옵션ID | 광고비 | ROAS | 매출 | 상품명` 및 합계 행 제공

## 🚀 실행 방법

### 1. npm 스크립트로 실행 (추천)
```bash
# 기본 크롤링 실행 (광고비 5,000원 이상 / ROAS 600% 미만)
npm run crawl
# 또는
npm start

# 화면 없이 백그라운드(Headless) 실행
npm run crawl:headless

# 조건 변경 실행 (인자 전달 시 앞에 -- 를 붙여줍니다)
npm run crawl -- --min-cost 10000 --max-roas 500

# 세션 만료 시 로그인용 브라우저만 먼저 띄우기
npm run login
```

### 2. 쉘 스크립트로 실행
```bash
# 기본 실행
./run.sh

# 조건 변경 실행
./run.sh --min-cost 10000 --max-roas 500
```

## ⚙️ 지원 옵션 (CLI Arguments)

| 옵션 | 기본값 | 설명 |
| :--- | :---: | :--- |
| `--min-cost` | `5000` | 최소 집행 광고비 (원 단위) |
| `--max-roas` | `600.0` | 최대 광고 수익률 ROAS (% 단위) |
| `--headless` | `False` | 브라우저 창을 띄우지 않고 백그라운드에서 실행 |
| `--output-dir` | `./output` | 결과 파일이 저장될 디렉토리 |
| `--profile-dir` | `./browser_profile` | 쿠키/세션이 보존되는 브라우저 프로필 디렉토리 |
